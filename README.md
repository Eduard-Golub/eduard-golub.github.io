# eduard-golub.github.io

Portfolio d'Eduard Golub, développeur IA et automatisation : https://eduard-golub.github.io/

Site statique en un seul fichier (`index.html`), sans framework ni étape de compilation.
GitHub Actions publie le contenu de la branche `main` sur GitHub Pages à chaque push.

Pour le voir en local :

```bash
python3 -m http.server 4173
```
